## 板子速览

- **48 × 24mm**，左上 R10 圆角，双面 2 层
- 编码器轴心 = 圆弧圆心 **(10, 14)**；SuperMini 贴背面，USB 朝下悬出 2.4mm，天线朝上入全层禁布窗
- 锂电充电：TP4054 @ **147mA**（R8=6.8k，换 2k≈500mA）+ SS34 电源自动切换 + B+/B− 焊线孔
- 定位柱：Ø3.0 孔 ×3，孔心 (4,3.5) / (44.5,3.5) / (44.5,20.5)，间距 40.5 / 17.0 / 43.9mm
- 焊线孔全部丝印标注；阻容值全部丝印标注

## 已知无害项（下单可忽略）

1. DRC 剩 1 处 VBAT 同网重叠（铜皮合并，零风险）
2. 背面器件**位号**文字未镜像（平台 API 限制）；**阻容值标注是实物正向的**，焊接以它为准
3. 板厂 DFM 的丝印压盘/锐角提示为顾问级，正常生产

## 首次上电顺序

1. 不接电池，USB 直插 SuperMini → 整机应正常
2. 断 USB 接电池 → 电池带机
3. 电池 + USB 同插 → CHG 灯亮=充电中，充满自灭
