## 自动布线接口情况

当前环境的 `pcb_Document.autoRouting()` 会在 0 ms 内返回全部网络失败，即使：

- 原理图与 PCB 逐焊盘网络一致；
- U1 的 UniqueId 已修复；
- PCB 已切换为 4 层；
- 飞线计算能够正常启动。

因此不能依赖该接口完成布线。后续应采用 API 手工分网布线，或在嘉立创 EDA 中使用前端布线功能。

## 投板限制

当前版本绝对不能直接投板。至少还需要：

1. 完成全部铜线和 GND 平面；
2. 建立 ESP32-C3 天线区域上下层禁铜、禁过孔、禁器件；
3. 复核 BQ24074 与 TPS61023 的高电流回路和散热；
4. DRC 中未布线错误归零，并处理真实间距错误；
5. 确认电池容量、允许充电电流、保护板、连接器极性；
6. 导出并复核 Gerber、BOM、CPL 和装配图。

## 当前关键风险

- 电池规格仍未确认，现有 `R1=1.78k` 对应的充电电流不应在未知电池上直接使用。
- SuperMini 自带 USB 与主板 5V 供电之间必须遵守防倒灌/烧录时断主电源要求。
- 贴片马达、蜂鸣器、编码器和连接器仍需结合实际外壳确认机械方向。
