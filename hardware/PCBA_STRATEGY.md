# 嘉立创 PCBA 装配策略

目标：嘉立创完成主板上除 ESP32-C3 SuperMini 外的全部器件贴装；收到板后，只手焊 SuperMini，
再插接 OLED 和外部电池/线缆（若采用）。

## 工厂贴装

| 功能 | 当前候选 | 贴装结论 | 设计注意 |
|---|---|---|---|
| 无源蜂鸣器 | MLT-5020 / C94598 | SMT | 约5.2mm、75dB、4kHz，必须配驱动 |
| 旋转编码器 | EC05E1220401 / C116648 | SMT | 约7.6×6.2×2.7mm，中空轴，需确认拨轮结构 |
| 确认/返回键 | EVQ-P7K01P / C5736840 | SMT | 独立替代原EC11内置按压，接GPIO20 |
| 振动马达 | LCM1027A3670F / C22359894 | SMT | 3V/80mA；嘉立创注明需要装配治具 |
| 触摸 | TTP223 + PCB 铜箔 | SMT/PCB 本体 | IC、电容工厂贴；触摸电极直接做在 PCB 上 |
| 驱动 | MOSFET、二极管、阻容 | SMT | 蜂鸣器、马达都不直接由 GPIO 带负载 |
| OLED 接口 | 待定 4P SMD 防呆座 | SMT | 必须同时确定线端插壳和端子，不只选板端座 |
| 电源器件 | 稳压器、滤波、开关等 | SMT | 最终随 USB 常供/锂电方案确定 |

这些候选在建立最终 BOM 时还要再次检查：库存、贴装面、旋转角度、封装版本和装配附加费用。

## 用户后焊/后装

| 项目 | 方式 |
|---|---|
| ESP32-C3 SuperMini | 平贴/短排针手焊到自定义 2×8 兼容封装 |
| OLED 屏幕板 | 使用预制线束插接，不焊主板 |
| 电池（若使用） | 插接到已由工厂贴好的板端座 |
| 旋钮帽 | 压入编码器轴 |

## PCB 工艺安排

- 尽量将所有自动贴装器件放在同一面，减少双面贴装成本和流程复杂度；
- SuperMini 放在另一面或留在同面独立空区，BOM/CPL 标 DNP；
- 马达、蜂鸣器、编码器均属于机械/声学器件，不能只看原理图，还要在 3D/装配图检查高度、开孔和
  受力；
- 蜂鸣器声孔上方不得被外壳或 SuperMini 遮挡；
- 振动马达附近应有足够板面支撑，避免放在窄悬臂或 PCB 开槽旁；
- 编码器按压会向 PCB 施力，附近布置安装孔或外壳支撑柱；
- PCBA 下单时查看马达治具提示和报价，若小批量治具费用不合理，再更换无需治具的封装/料号，而
  不是临时改为手焊。

## 验收顺序

1. 收到已贴装主板后，先不焊 SuperMini，检查 5V/3.3V 对地是否短路；
2. 用限流电源给主板供电，检查稳压轨；
3. 手焊 SuperMini；
4. 首次上电限制电流，先验证 OLED/I2C 和输入器件；
5. 再分别测试蜂鸣器、马达，最后测试同时工作和 Wi-Fi 发射时的电源稳定性。
