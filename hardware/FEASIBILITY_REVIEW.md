# AgentBell 集成 PCB 可行性评审（2026-07-18）

## 结论

这些功能可以集成到同一块主 PCB：

- ESP32-C3 SuperMini 主控子板
- 无源蜂鸣器及驱动
- 振动马达及驱动、续流保护
- 电容触摸按键
- 带按压的旋转编码器
- OLED 屏幕外接接口
- 电源输入、滤波、测试点和调试接口

屏幕继续做独立板很合理。第一版建议把主板定位为 **SuperMini 载板**，而不是立即把
ESP32-C3 芯片、Flash、晶振、USB 电路全部重画一遍。这样既能沿用现有固件，又能显著降低 RF、
USB 下载和焊接风险。

用户已确认装配目标：**除 ESP32-C3 SuperMini 手焊外，其余主板器件尽量全部由嘉立创贴装。**
现有候选蜂鸣器、编码器和振动马达均有嘉立创 SMT 条目；其中振动马达需要装配治具。详细安排见
[PCBA_STRATEGY.md](PCBA_STRATEGY.md)。

目前目录内的 `SCHEMATIC.md`、`BOM.csv` 是前期方案，不应直接用于下单。打板前还需要完成：

1. 确认所有实物的机械尺寸和引脚顺序；
2. 决定 USB 常供电还是锂电供电；
3. 确认 SuperMini 能否平贴焊接；
4. 用最终选定的立创商城料号核对封装、库存和贴装属性；
5. 画出真实 EDA 原理图/PCB，完成 ERC、DRC、Gerber 和坐标文件检查。

当前暂定首版为 USB 常供电，以便先完成明确且低风险的载板设计。如果用户确认必须加入锂电，正式
原理图将切换到带充电、保护和电源路径的版本。

## 从代码确认的接口

固件 `agent_bell/agent_bell.ino` 当前使用：

| 功能 | GPIO | 电气方向/说明 |
|---|---:|---|
| 编码器 A | 1 | 输入，上拉，双边沿中断 |
| 蜂鸣器 | 3 | PWM/音调输出；当前固件按“低有效 PNP 驱动”编写 |
| 触摸 | 4 | 数字输入；固件会在启动时学习空闲电平 |
| OLED SDA | 5 | I2C，3.3V |
| OLED SCL | 6 | I2C，3.3V |
| 编码器 B | 7 | 输入，上拉，双边沿中断 |
| 振动马达 | 10 | 20kHz PWM，高有效 |
| 编码器按键 | 20 | 输入，上拉，按下接地 |

代码避开了 GPIO2、GPIO8、GPIO9，并保留 GPIO0、GPIO21。PCB 上应把 0、21、3V3、GND、EN
做成测试焊盘，便于首板调试。

## 推荐的首版架构

### 方案 A：USB 常供电载板（推荐首板）

使用 SuperMini 自带 USB-C 负责供电和烧录：

```text
SuperMini USB-C
  ├─ 板载稳压器：只负责 SuperMini 自身 3.3V
  └─ 5V/VBUS 焊盘 → 载板 3.3V 稳压器 → OLED/触摸/编码器/蜂鸣器/马达
                                      └→ 蜂鸣器、马达各自经过驱动
```

优点：电路少、没有双 USB 口、没有充电和电源路径问题，最适合验证布局、交互和驱动电路。

新增资料已经确认 SuperMini 引出了 5V/VBUS、GND 和 3.3V。载板默认从 5V/VBUS 取 USB 电源并
自行稳压，不把两个 3.3V 稳压器输出并联。开发板资料明确要求外部供电和 USB 不能同时使用；详见
[SUPERMINI_CARRIER_SPEC.md](SUPERMINI_CARRIER_SPEC.md)。

### 方案 B：锂电版（第二版或确认需求后再做）

锂电版需要同时考虑电芯保护、充电电流、边充边用的电源路径和低电压关断。当前草案的
“TP4056 + LDO 直接带载”可以工作于某些场景，但不适合在参数未确认时直接出板：

- TP4056 本身不是完整的负载共享/电源路径管理；
- 1.2kΩ PROG 约对应 1A 充电，未必适合小电池；
- 电池电压下降后，普通 3.3V LDO 会逐渐失去稳压余量；
- 电池保护取决于电芯是否自带保护板；
- SuperMini 自带 USB 和主板充电 USB 同时插入时必须避免电源互相顶住。

如果确实需要电池，建议单独确定续航、充电口数量、电池容量和是否要求边充边用，再选择带
power-path 的充电方案或做明确的电源隔离。

## 各模块怎样集成

### 1. ESP32-C3 SuperMini

新增资料确认该版本约 18.00 × 22.50 mm、2×8 焊盘、两排基准间距 15.24 mm。首版做
**混合兼容手焊封装**：通孔用于定位/加固，外侧加长焊盘用于模块平放后的烙铁接触。模块覆盖区不
放元件，天线端伸出主板或做完整禁铜区。正式投板前仍需用 1:1 封装打印图与手头实物叠放核对。

### 2. 无源蜂鸣器

用户提供的 PDF 显示模块由无源蜂鸣器、9012 类 PNP 三极管和基极电阻组成，是低有效高边驱动。
PDF 上电阻标注为 22Ω；不建议未经实测就原样复制，尤其不应把该模块直接以 5V 供电并由 3.3V
GPIO 驱动。

推荐主 PCB 使用裸无源蜂鸣器 + 独立驱动：

- 首选逻辑电平 N-MOSFET 低边驱动，蜂鸣器电源可通过焊接跳线选择 3.3V/5V；
- GPIO 只驱动 MOSFET 栅极，不承担蜂鸣器电流；
- 采用低边驱动后，需要把固件蜂鸣器极性改为高有效；
- 若坚持完全不改固件，可保留 3.3V PNP 高边方案，但不要提供未经电平转换的 5V 档。

如果要拆现有模块上的蜂鸣器复用，必须测量蜂鸣器本体尺寸、脚距，并确认它确实是无源型号。

### 3. 振动马达

马达不能直接接 GPIO。推荐使用逻辑电平 N-MOSFET 低边驱动，并在马达两端放续流二极管。马达
附近增加 0.1µF 抑制电容，负载电源入口增加储能电容，电机大电流回路不要穿过 ESP32/OLED 的
地回路。

淘宝模块整板通常不能作为标准 SMT 料自动贴装。可选择：

- 主 PCB 做马达驱动，保留 2P 焊盘/连接器，复用现有马达；
- 选立创可贴的 SMD 币式马达，但必须用其官方封装并确认装配限制；
- 首板由你手工焊马达，风险最低。

### 4. 触摸开关

最适合集成：不再安装淘宝触摸模块，而是把 TTP223 类触摸 IC、去耦电容和触摸铜箔直接画在
主 PCB 上。触摸电极周围及其正下方要按触摸设计留出净空，并预留灵敏度电容焊盘。

如果触摸区域隔着较厚外壳，需先确定外壳材料和厚度；这会直接影响铜箔面积和灵敏度。

### 5. 旋转编码器

小型版不再使用 HW-040/大 EC11。当前优先候选为 `EC05E1220401 / C116648`，约
7.6×6.2×2.7mm，由嘉立创贴装。它使用中空轴转轮，若不带按压，则增加
`EVQ-P7K01P / C5736840` 小型贴片按键接原 GPIO20，固件功能保持不变。机械结构仍需在外壳阶段
确认拨轮直径、手指接触空间和按键位置。

### 6. OLED

屏幕分板保留。主板提供 4P 防呆连接器，并把引脚顺序同时印在丝印上：`3V3/GND/SDA/SCL`。
连接器型号和屏幕端线序必须最终确认；不能只写“JST 4P”，因为 PH、SH、XH 的间距完全不同。

## 嘉立创下单时哪些可以直接贴

“可以直接有”并不只取决于它是不是 SMD，还取决于下单当日的库存、封装、贴装面、器件高度和
装配规则。因此最终以立创 EDA/JLCPCB 下单页的 BOM 匹配结果为准。

| 类别 | 建议 | 原因 |
|---|---|---|
| 0402/0603/0805 阻容、LED | 工厂贴 | 标准 SMT，最适合自动贴装 |
| MOSFET/三极管、二极管、TTP223、电源 IC | 工厂贴 | 有明确 LCSC 料号和封装即可 |
| USB-C、常见 SMD JST 座、滑动开关 | 可工厂贴 | 需锁定精确料号、开口方向和机械孔 |
| SMD 蜂鸣器 | 工厂贴 | 小型版候选 C94598，约5.2mm，必须配独立驱动 |
| SMD 薄型编码器 | 工厂贴 | 小型版候选 C116648；独立确认键 C5736840 |
| 币式振动马达 | 工厂贴 | C22359894 当前候选支持 SMT，但需要装配治具 |
| ESP32-C3 SuperMini 整板 | 手焊 | 淘宝开发板不是标准 LCSC SMT 物料；平贴还依赖实物边缘焊盘 |
| 淘宝触摸/蜂鸣器/马达/HW-040 模块整板 | 手焊或取消模块 | 模块通常没有标准 PCBA 贴装料号和机器可识别包装 |
| OLED 模块、旋钮帽、锂电池、外接线 | 后装/手工装配 | 属外部模块或机械装配件 |

用户自己提供的散件并不等于经济型 PCBA 会自动帮忙贴。若要让工厂使用客供料，通常需要走
客供料/特殊装配流程并增加沟通和成本；对 5～10 块首板，自己焊关键机械件更合适。

## 首版 PCB 的建议边界

首版目标应是“电气可靠、接口正确、能装进预期外壳”，而不是一次把所有特殊器件都交给工厂贴：

- JLC 贴：阻容、MOSFET、二极管、触摸 IC、连接器、蜂鸣器、编码器、振动马达；
- 你手焊：仅 SuperMini；OLED、电池等使用插接线束后装；
- PCB 同时给蜂鸣器和马达留替代封装/2P 接口，避免某一个淘宝器件尺寸不合导致整板报废；
- 所有外接接口旁标注电压、信号名和 1 脚；
- 预留 0Ω/焊接跳线用于选择蜂鸣器/马达电源和调整触发极性。

完成首板验证后，再把已确认的蜂鸣器、马达、编码器改成 JLC 全贴版本，成功率会高很多。
