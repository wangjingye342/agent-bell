# AgentBell 锂电、USB 优先和边充边用电源架构

更新日期：2026-07-18

## 已确认的使用行为

1. 未插 USB：单节锂电池给整机供电；
2. 插入主板 USB-C：USB 优先给整机供电；
3. 电池未满：USB 同时给系统供电并给电池充电；
4. 电池充满：充电自动终止，系统继续由 USB 供电；
5. USB 供电能力不足或负载出现短时峰值：充电电流先降低，必要时电池辅助系统；
6. 拔掉 USB：自动转为电池供电，不需要用户切换电源来源；
7. 电源开关 OFF：关闭整机负载，但 USB 插着时仍允许电池充电。

这需要真正的 power-path/load-sharing 充电管理器，不能用 TP4056 的 BAT 节点直接并联系统负载。

## 暂定主芯片

| 功能 | 型号 | LCSC | 封装 | 状态 |
|---|---|---|---|---|
| 单节锂电充电 + 动态电源路径 | BQ24074RGTR | C54313 | QFN-16-EP 3×3 mm | 正式候选 |

选择原因：

- 嘉立创器件库已有符号、封装和 3D 模型；
- 支持单节 4.2V 锂电；
- OUT 系统节点可由 USB 输入或电池自动供电；
- 系统负载优先，输入能力不足时自动降低充电电流；
- 支持电池补充系统峰值电流；
- 输入限流、快充电流和终止电流均可通过外部电阻配置；
- 提供 CHG、PGOOD 状态和电池 NTC 温度检测。

最终投板前必须按 TI 最新数据手册逐脚复核，而不是只依赖库符号。

                      ├─► 隔离/防倒灌 ──► SuperMini 5V 脚

## 为什么后级需要升压

BQ24074 的系统输出在插 USB 时约为固定系统电压，拔掉 USB 后会接近电池电压。电池从满电到低电
期间不足以始终作为稳定的“5V”。ESP32-C3 SuperMini 又保留了自己的板载 3.3V 稳压器，所以首版
不直接并联主板 3.3V 与 SuperMini 3.3V，而是：

1. 把 VSYS 升压为稳定 `5V_SYS`；
2. 通过防倒灌器件送入 SuperMini 的 5V 焊盘；
3. SuperMini 使用自身稳压器供给自己的 ESP32-C3；
4. 主板另从 `5V_SYS` 生成外设 3.3V。

升压器需要：

- 输入覆盖单节锂电工作范围；
- 5V 输出能力满足 Wi-Fi、蜂鸣器和马达同时动作；
- 有 EN 引脚，供机械电源开关控制；
- 关闭时低静态电流；
- 输出侧尽量具有真关断或增加独立负载开关/反向电流阻断。

具体升压芯片和 LCSC 料号将在估算整机峰值电流后锁定。

## 两个 USB-C 的使用规则

主板会有两个物理 USB-C：

| 接口 | 用途 |
|---|---|
| 主板 USB-C | 日常供电、给电池充电、边充边用 |
| SuperMini 自带 USB-C | 固件烧录/调试服务口 |

SuperMini 原理图显示其 5V 焊盘与自身 USB-C VBUS 直接相连。电池模式下由主板给该 5V 焊盘供电
时，其 USB-C VBUS 也可能出现电压。因此：

- 日常使用只插主板 USB-C；
- 使用 SuperMini USB-C 烧录前，必须把主电源开关拨到 OFF；
- 主板给 SuperMini 的 5V 支路加入反向电流阻断，防止烧录 USB 反灌回系统电源；
- PCB 丝印在 SuperMini USB 旁标注 `PROGRAM: POWER OFF FIRST`；
- 外壳设计可把 SuperMini USB 作为隐藏服务口，降低误插概率。

## 电源开关逻辑

开关不串在电池和充电芯片之间，而是控制后级系统电源：

```text
OFF：升压器/系统负载关闭；BQ24074 仍可给电池充电
ON ：升压器开启；系统由 BQ24074 OUT 供电，USB/电池来源自动选择
```

这种方式避免大电流全部流过小型机械开关，也允许关机充电。

## 电池保护和温度

- 如果使用带保护板的成品 LiPo，主板仍保留保险/反接防护和电池 NTC 接口；
- 如果电池不带保护板，主板必须加入单节电池过充、过放、过流和短路保护；
- 优先使用带 10k NTC 的 3 线电池；若最终电池只有 2 线，TS 网络必须严格按 BQ24074 数据手册
  设置，不能悬空猜接；
- 电池连接器必须明确 1 脚和极性，不能假设不同厂家的 JST 线序一致。

## 尚待电池参数决定的数值

以下参数不能在不知道电池规格时定版：

- 快充电流 `ICHG` / ISET 电阻；
- 充电终止电流 / ITERM 电阻；
- USB 输入电流上限 / ILIM 电阻；
- 是否装主板电池保护；
- NTC 网络；
- 电池电压检测分压和固件低电量阈值。

需要提供：电池标称容量、最大充电电流、是否带保护板、2 线/3 线、接头型号和实物极性照片。
