# ESP32-C3 SuperMini 载板接口与封装要求

依据目录 `ESP32C3-Supermini-main` 中的尺寸图、原理图和 Altium `PcbDoc` 整理。

## 已确认尺寸

| 项目 | 数值 |
|---|---:|
| 模块最大宽度（含两侧焊盘） | 18.00 mm |
| 模块长度 | 22.50 mm（资料文字写 22.52 mm） |
| 两排焊盘基准间距 | 15.24 mm |
| 每排焊盘数量 | 8 |
| 纵向焊盘节距 | 2.54 mm |

最终封装以资料内 `Hardware/Super Mini-ESP32C3-外形.PcbDoc` 导入后的机械层和焊盘坐标为准，
图片尺寸用于交叉检查。

## 引脚顺序

观察方向：SuperMini 元件面朝上、USB-C 在上、天线端在下。

```text
              USB-C
       ┌─────────────────┐
GPIO5  │ L1           R8 │ 5V / VBUS
GPIO6  │ L2           R7 │ GND
GPIO7  │ L3           R6 │ 3.3V
GPIO8  │ L4           R5 │ GPIO4
GPIO9  │ L5           R4 │ GPIO3
GPIO10 │ L6           R3 │ GPIO2
GPIO20 │ L7           R2 │ GPIO1
GPIO21 │ L8           R1 │ GPIO0
       └──────天线端─────┘
```

本项目用到的脚全部能够从两侧焊盘取得：GPIO1、3、4、5、6、7、10、20、GND，以及按电源方案
选用的 5V/VBUS。

## 供电关系

SuperMini 原理图显示：

```text
USB-C VBUS ──肖特基二极管── VSYS ──板载 3.3V LDO── ESP32-C3
      │
      └────────────────────────────── 5V/VBUS 焊盘
```

开发板资料明确要求外部供电和 USB 不能同时使用。载板设计因此遵守：

1. 首版只使用 SuperMini 自带 USB-C 作为整机电源入口和烧录口；
2. 载板从 SuperMini 的 `5V/VBUS` 焊盘取得 USB 5V；
3. 载板使用自己的 3.3V 稳压器给蜂鸣器、马达、触摸、编码器上拉和 OLED 供电；
4. 载板 3.3V 与 SuperMini 的 3.3V 输出默认不短接，避免两个稳压器并联；
5. 所有电路共地；
6. 若以后加入锂电或主板 USB-C，必须增加明确的电源选择/隔离，不能同时向 5V/VBUS 灌电并插
   SuperMini USB。

首板画完后应实测 USB 供电时 `5V/VBUS` 焊盘电压，并检查蜂鸣器+马达同时工作时的压降。

## 手焊封装策略

SuperMini 是唯一的后焊件。载板做一个自定义 `ESP32C3_SUPERMINI_HAND_SOLDER` 封装：

- 两排 8 个连接位，中心距 15.24 mm、节距 2.54 mm；
- 载板焊盘向模块外侧加长，保证模块平放后烙铁仍能从外侧接触焊盘；
- 同时保留与模块通孔对应的钻孔，允许使用短排针加固或返修；
- 丝印明确标出 `USB`、`ANT`、`5V`、`GND`、`GPIO0`、`GPIO21`；
- USB-C 插拔方向不得被主板边框、外壳或编码器遮挡；
- 模块本体覆盖区内不放任何元件、过孔或高焊点；
- 天线端优先伸出载板边缘；做不到时，天线下方和前方全部禁铜、禁走线、禁放元件；
- GPIO0、GPIO21、EN/复位相关调试需求可通过模块自身按键和额外测试点处理；
- 在正式投板前，用 1:1 打印的封装图与实物叠放检查。

## 载板原理图符号建议

不要用两个没有语义的 `Header 8`。建立一个 16 引脚模块符号，脚名与上述真实引脚一致。这样 ERC、
BOM 排除和装配图都更清楚。

该器件属性设置为：

- `DNP / Do not populate`；
- 不进入嘉立创贴片 BOM/CPL；
- 装配说明标记 `USER HAND SOLDER AFTER PCBA`。
