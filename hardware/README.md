# AgentBell 单板 PCB — 设计源

把 AgentBell 从"面包板+杜邦线"集成到**一块嘉立创可打样+贴片**的板子。
本目录是**设计源**（原理图连接表 + BOM + 布局），在 **立创EDA(EasyEDA)** 里照此连线即可一键下单打板贴片。

> ⚠️ 工具现实：这份是"人可读的设计包"，不是可直接上传 JLC 的 Gerber/CPL。实际布线/DRC/出 Gerber
> 需在 EDA 工具里做。推荐 **立创EDA**（JLC 自家、LCSC 元件直接按编号搜、一键下单贴片）。

## 方案总览

- **主控**：ESP32-C3 SuperMini，用 **2×8 母排针座**插在主板上（可插拔、好返修）。它是 2.54mm 直插脚、不是城堡孔，做不了真·回流贴片。天线短边**悬出板边、其下方主板挖空无铜**。
- **屏**：0.96" SSD1306 OLED（单独一块），主板出 **4P 排线座**（3V3/GND/SDA/SCL）引到外壳正面。
- **全 SMD 由 JLC 贴**：无源蜂鸣器 MLT-8530、SMD 版 EC11 编码器、SMD 币式振动马达，及全部驱动三极管/二极管/阻容/触摸 IC/电源芯片。
- **触摸**：不用触摸模块——在 PCB 顶层做一块**铜箔触摸片**接 TTP223（周围挖空地铜、盖阻焊、丝印画图标）。
- **供电**：锂电 + USB-C 充电（TP4056）+ 电源开关 + 3.3V LDO。
- **手工焊/装配**：SuperMini（插母座）、锂电（JST）、OLED（排线）。其余 JLC 贴好。

## 供电架构

```
USB-C(充电口) ──► TP4056 ──► 锂电池(JST-PH2.0)
                    │           │
                 CHRG/STDBY   VBAT ──► [电源开关] ──► LDO 3.3V(≥600mA) ──► 3V3 总线
                 状态LED                                                    │
                                                         ┌──────────────────┼──────────────┐
                                                    SuperMini(3V3脚)   蜂鸣/马达/触摸/编码器   OLED(排线)
```
- **编程**：用 SuperMini 自带的 USB-C（数据在芯片内，排针引不出）。**编程时把电源开关拨到 OFF**，
  避免 LDO 输出与 SuperMini 自带稳压器的 3V3 打架（此时 USB 经 SuperMini 反供 3V3 给外设，正常）。
- 3.3V 总线上放 **100µF 体电容**吸收 WiFi 发射瞬时电流；马达峰值约 150–200mA，故 LDO 选 ≥600mA。
- 充电与使用可同时（TP4056 直接带载，简化方案；不做 load-sharing）。

## 引脚分配（沿用现固件，避开 strapping 2/8/9）

| GPIO | 功能 |
|---|---|
| 1  | 编码器 CLK (A) |
| 3  | 蜂鸣器（经 SS8550 低有效驱动）|
| 4  | 触摸（TTP223 输出）|
| 5  | OLED SDA |
| 6  | OLED SCL |
| 7  | 编码器 DT (B) |
| 10 | 振动马达（经 SS8050 高有效驱动）|
| 20 | 编码器按键 SW |
| 3V3/GND | 供电 |
| 空闲 | 0, 21（可留调试焊盘）|

## 平面布局（紧凑手掌方块，建议约 50×40mm）

```
┌───────────────────────────────────────┐
│  [USB-C 充电]        [电源开关]  ●●充电灯 │  ← 一条短边：充电口+开关+状态灯
│                                         │
│   ┌─ SuperMini(母座) ─┐     ○ 旋钮       │  ← SuperMini 天线端朝这条边、悬出、下方挖空
│   │  天线端悬出↑挖空   │    (EC11 编码器) │
│   └──────────────────┘                  │
│   ▣ 触摸铜箔片        [OLED 4P 排线座]►  │  ← 触摸片=顶层铜箔；OLED 用排线引出
│   ·蜂鸣器  ·马达   (SMD，贴在背面/角落)   │
└───────────────────────────────────────┘
   背面：锂电池（双面胶/JST）
```
- 编码器、触摸片放正面顺手位置；蜂鸣器/马达可放背面或边角。
- SuperMini 天线短边务必伸出板边、正下方无铜无地。

## 嘉立创下单要点

1. 在立创EDA 画原理图（按 `SCHEMATIC.md` 连接表）→ 导入元件（按 `BOM.csv` 的 LCSC 编号）→ PCB 布局布线 → DRC。
2. 下单：PCB + **SMT 贴片（Economic PCBA）**；本板 Extended 料不多（TTP223/蜂鸣器/EC11/马达），留 Economic 即可。
3. **不贴、留给你手工**：SuperMini 母座（THT）、锂电 JST、OLED 排线座——这些做成 THT 或你自己焊。
4. 收板后：焊/插好母座与连接器 → 插 SuperMini → 接电池与屏 → 烧录固件（`secrets.h` 填 WiFi）。

详见 [SCHEMATIC.md](SCHEMATIC.md)（逐块原理图+连接表）与 [BOM.csv](BOM.csv)（元件+LCSC 编号）。
