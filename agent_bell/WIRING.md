# AgentBell 接线（ESP32-C3 SuperMini）

固件里用 **GPIO 号**（逻辑通用）；SuperMini 丝印直接标 GPIO 数字。
若换别的板子（XIAO 丝印是 D0–D10 等），照 GPIO 号找对应脚即可，代码不用改。

## ⚠ 电压：ESP32-C3 不耐 5V

1. **旋转编码器的 `+` 必须接 3V3**：它的 CLK/DT/SW 输出电平跟随供电脚，接 5V 会把 5V 打进
   GPIO 烧芯片。编码器本体无源，3.3V 完全能用（虽然模块标称 5V）。
2. **OLED、触摸的 VCC 也必须 3V3**（触摸 SIG 直连 GPIO）。
3. **蜂鸣器 / 震动**：先接 3V3；若太弱，这两个的 VCC 可改接 **5V(VBUS)**——它们的控制脚仍由
   3.3V GPIO 驱动、只输出不回读，5V 不会进 GPIO，安全。
4. **所有 GND 共地**。

## 旋转编码器调校

- **方向反了**：把 `agent_bell.ino` 顶部的 `// #define ENC_REVERSED` 取消注释，重新烧录。
- **转一档跳好几格 / 跳不动**：调 `ENC_DIV`（默认 4；跳多格就减小，跳不动就增大）。
- **按键**：短按=确认/进入，长按≈0.5s=返回。

## 用法（编码器菜单）

- 待机（太空人）**转动或按一下** → 进主菜单。
- 主菜单：**转**=移动光标（丝滑滚动），**短按**=进入/确认/切换，**长按 或 触摸键**=返回上一级/回待机。
- 提示音子菜单：转到某项**停 0.3 秒自动试听**，短按=选用。
- 蜂鸣/震动强度：进去后**转**=调整（即时试声），按/触摸=保存返回。
- 菜单里 **15 秒无操作**自动回待机；来通知会打断任何界面并响铃。

## 避坑：strapping 脚

已避开 **GPIO2 / GPIO8 / GPIO9**（板载蓝灯在 8、BOOT 键在 9）。当前用的 1/3/4/5/6/7/10/20 都是安全脚。

## 蜂鸣器 / 震动极性

蜂鸣器是**无源**的，靠方波发声，无极性开关。震动模块若"常震/不震"，翻 `agent_bell.ino` 顶部
`VIB_ACTIVE_HIGH`。

## OLED I2C 地址

默认 `0x3C`；少数屏是 `0x3D`。不亮就改 `agent_bell.ino` 里的 `OLED_ADDR`。

## 🔒 麦克风（以后录音用）

（可能需要复用触摸脚或调整分配）。
